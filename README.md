# 💳 Credit Card Fraud Detection

A machine learning project to detect fraudulent credit card transactions using data analysis and classification algorithms.

## 🎯 Objectives

* Perform Exploratory Data Analysis (EDA).
* Handle imbalanced transaction data.
* Train and evaluate machine learning models.
* Compare model performance using Precision, Recall, F1-score, and PR-AUC.

## 📊 Dataset

[Kaggle — Credit Card Fraud Detection](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

The dataset contains 284,807 transactions, including 492 fraudulent transactions.

## 🛠️ Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost.

## 🚀 Installation

```bash
git clone https://github.com/mdfokrulakon/Credit_Card_Fraud_Detection.git
cd Credit_Card_Fraud_Detection
pip install -r requirements.txt
```

Download the dataset from Kaggle and run the notebooks in order.

## 📈 Evaluation

Models are evaluated using Precision, Recall, F1-score, PR-AUC, and Confusion Matrix. The final model will be selected based on actual test-set performance.
